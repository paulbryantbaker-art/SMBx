### Voice
Yulia: expert M&A deal intelligence, never "As an AI", specific over generic, numbers over adjectives, memo-tight prose. No "seamless/leverage/unlock/empower/delve/robust", no exclamation decoration, no bullet-lists where prose reads better. Site copy: describe the work, never a competitor; corp-dev category (not "cheaper bank"); AI-language demoted; buy-side loyalty warm, once; track-record attribution law (led or co-led · selected transactions · anonymized employers · 150 acquisitions); no fees anywhere public.

### Motion
- Animate only `transform` and `opacity` (GPU-composited)
- Never `transition: all` — list specific properties
- Honor `prefers-reduced-motion` always; provide static beautiful alternatives
- **No bounce, no elastic** — this is finance + editorial, not a toy
- Custom easing curves over CSS defaults: ease-out `cubic-bezier(0.23, 1, 0.32, 1)`; ease-in-out `cubic-bezier(0.77, 0, 0.175, 1)`; iOS drawer `cubic-bezier(0.32, 0.72, 0, 1)`
- **Never `ease-in` on UI** — feels sluggish at the moment users are watching most closely
- Micro-interactions: `active:scale-[0.97]` on buttons (not 0.95 — too much), 100–160ms button feedback, 200ms tool popups, 300ms theme transitions
- UI animation duration cap: **300ms**. Exit animations ~70% of enter duration.
- Popovers: `transform-origin` from trigger (use Radix `--radix-popover-content-transform-origin`). Modals exempt — keep centered.
- Never animate from `scale(0)` — start from `scale(0.95) opacity:0`. Nothing in real life appears from nothing.

### Accessibility
- WCAG 2.1 AA across the board
- All interactive elements keyboard-accessible with visible focus rings
- Contrast: 4.5:1 body text, 3:1 large text + UI components
- Touch targets: minimum 44px on mobile, 8px+ spacing between
- Respect `prefers-reduced-motion`, `prefers-color-scheme`, system text scaling
- No hover-only affordances on touch surfaces
- **No long-press gestures anywhere** — visible ⋯ menus, swipe actions, or dedicated buttons. (See memory: `feedback_no_long_press.md`.)
- Color is never the only indicator (icons + text accompany state colors)

### Design Principles
1. **Substance over decoration.** Every pixel earns its place. No decorative eyebrows or micro-labels; no customer-facing text below 13px; lead with the real header.
2. **Financial precision is non-negotiable.** Tabular nums on every number column; right-align currency; never round to clean numbers; money stored in cents (integers). **Zero hallucination on financial data** — extract exactly, never invent, cite the source.
3. **Mobile browser first.** Mobile and desktop are separate front-ends — never share a div with conditional styles. Portal mobile fixed chrome to `document.body` (ancestor `transform`/`filter` breaks `position:fixed`).
4. **Documents are the deliverable.** Reports, 1-pagers, carousels, memos must look like a boutique advisory produced them. "Would a top-tier firm send this?" is the test. In-browser review/approve — never require download to interact.
5. **Yulia is the interface** inside the app; on the public site the intake engine and the booking card are the only two conversions.
6. **Editorial restraint.** Typography carries the design; two-width law (1360 rail / 1040 artifact); giant numerals are the drama, used sparingly.
7. **Safari toolbar tinting is real.** Never `position:fixed` full-viewport divs with `background-color` — use `position:absolute` inside a `relative` parent. (See memory: `feedback_safari_toolbar_tinting.md`.)
