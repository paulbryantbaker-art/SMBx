# The in-house attempts, and Paul's verdicts — read before designing

These six JPGs are what the practice's own renderer produced across eight
rounds of correction. Paul's final verdict: "you cannot do it" — hence this
brief. His reactions, verbatim, in order:

- First offer build (5 pages): "i dont hate it, but the content seems pretty
  sparse... give the viewer a better sense of 'this is how we run corp dev'!
  The CTA page is also super boring!"
- Expanded build (11 pages): "maybe in the upper right, we say 'Outsourced
  Corporate Development for Private Equity and Family Offices'... it is too
  many pages, we can consolidate and tell a better story!"
- Consolidated build (8 pages): "now i a carousel post on linkedIn, none of
  this text is going to be legible. we need to think of it as mobile."
- Dead-deal build: "why did you make every page the same as the cover page?"
  (the monolith is a COVER treatment — bookend law) · "The CTA page is
  supposed to be my headshot, with a follow-up question and a clear CTA, not
  a mirror image of the cover page." · "the logo gets kind of lost in the
  corner... move the logo [lower-left] and use Golden Ratio to size and
  position it." · on the headshot: "it looks like i have no neck" → the
  Frame C φ-rectangle in the brief.

What the attempts got RIGHT (keep): the bookend structure, the verb arc
(FIND · DECIDE · CLOSE · OWN), Frame C, the plated CTA choice, the φ logos,
the mobile type floor on the final offer build.

What they never achieved (your job): body pages with real graphic PRESENCE —
they read as sparse type floating on white — and a swipe that feels like one
designed object rather than pages that merely match.
